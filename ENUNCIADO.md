# Enunciado — Pruebas Android con Espresso y UIAutomator

Crear una aplicación Android mínima —un contador— y cubrirla con dos niveles de pruebas instrumentadas:

1. **Espresso** debe verificar comportamiento dentro de la propia aplicación, por ejemplo que pulsar `Increment` cambia el valor de `0` a `1`.
2. **UIAutomator** debe demostrar interacción con la interfaz del sistema o fuera del proceso de la app, por ejemplo navegando al launcher.

El proyecto debe compilar tanto la APK de depuración como la APK de pruebas instrumentadas. La ejecución completa requiere emulador o dispositivo Android.

No existe una base de datos asociada.
